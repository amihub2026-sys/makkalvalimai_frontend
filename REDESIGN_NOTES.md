# Approved visual direction

Use the client-selected **medium-blue and red** desktop homepage, long-form article and native-app-like mobile reference `docs/approved-reference.png`. The shared color tokens are in `src/styles/tokens.css`, and mobile styles are in `*.component.responsive.css` per section. Do not add fabricated posts, votes, ads, incidents, locations, temperatures, images or fake metrics merely to fill empty areas. Empty and loading states are intentional until the real API returns records.

The source refactor preserves the existing backend API routes without making changes to the backend. The reference artwork is a visual goal, not a claim of current pixel-perfect live browser rendering.
